# Disclaimer

## What this project is, and is not

This repository contains **software**. It is a personal programming project — an
exercise in grounding a language model's output against verifiable data — and it
exists to be read as code.

It is **not** an investment advisory service, a research service, or a source of
recommendations regarding securities.

- **No output is published here.** Generated reports are excluded from the
  repository by `.gitignore`. Nothing in this repository tells anyone to buy,
  sell, or hold any security.
- **Nothing here is a recommendation.** The program produces exploratory notes
  written by a language model. Its verdicts are unreliable by construction, and
  the project documentation says so at length.
- **It has never been validated.** The output has never been tested against
  whether it identifies profitable positions, or against any labelled set of
  past situations. See "Does it work?" in the README — the honest answer is that
  nobody knows.
- **No consideration is sought or accepted** for this project or anything it
  produces. It is not offered as a service to anyone.

and is responsible for their own investment decisions and their own compliance
